# Office Viewer · 大文件免费版

基于 [Office Viewer](https://github.com/cweijan/vscode-office) 的本地修改。保留 MIT 许可证与原作者版权。上游发布版基础：4.2.3；本地扩展 ID：`local.office-largefile-local`。使用独立 ID，避免商店更新覆盖修改。

## 使用

按下方重建步骤生成并安装 VSIX 后，在 VS Code 运行 `Developer: Reload Window`。Markdown 默认使用所见即所得编辑器。大于 48000 字符或超过 400 行的文件自动分页，默认每页约 320 行／48000 字符（不拆开代码围栏和 YAML 头）。顶部支持翻页、跳页、搜索整篇文件，回车找下一个，Shift+回车找上一个。

默认启用自动翻页：滚到页底后继续下滚进入下一页开头；页顶继续上滚返回上一页末尾。PageDown／PageUp 也可在页边界翻页。滚轮惯性有保护，一次手势只翻一页；选中文字、中文输入法组字、代码编辑控件内的操作不会触发自动翻页。

“每页容量”可选 160 行／24000 字符、320 行／48000 字符、640 行／96000 字符，替代原先的 80 行／12000 字符。容量和自动翻页开关保存在本地。容量是目标边界，完整代码块等不可拆分结构可超出限制。切换容量前先合并当前页修改，再重新分页，保存仍为完整 Markdown 文件。

分页仅影响显示，磁盘仍是同一个 Markdown 文件。Cmd+S 和保存按钮均保存完整文件。重复表头不可编辑，请去该表格第一页修改。撤销仅针对当前页面；跨页后会清空页面内的撤销栈，防止把另一页的内容撤销到当前页。可用顶部“源码”切换到完整源码，使用 VS Code 自带文件撤销。

普通小文件继续完整显示。单个巨大代码块不会拆分，仍可能渲染较慢。Markdown 引用定义或脚注若位于其他页，当前页可能无法完整显示关联内容，可切换源码查看。

## 修改内容

- `largeDocument.mjs`：精确来源区间、表格续页、局部合并、全文搜索、CRLF 保留。
- `largeDocumentUI.mjs`：分页控件、全文搜索跳页、高亮、重复表头保护。
- `index.js`：接入分页显示，并将输入、显式保存、外部更新统一映射为完整文档。
- `util.js`：修复 Cmd+S 路径，避免只保存当前页。
- `index.css`：分页栏布局。

本地免费版将已打包功能统一开放，无需激活：快捷键查看与自定义、字体颜色与背景色、图片缩放、思维导图／关系图、导出主题与字体／字号／页面设置，以及 PDF 工具。信封升级入口已移除，原激活命令改为本地版说明。

- `local_features.py`：针对官方 4.2.3 桌面与 Web 宿主的可审阅构建变换。启用查看器能力、PDF 工具与状态广播，关闭已取消账户造成的界面锁定及启动时的授权刷新；不生成密钥、不改写账户授权存储。
- `index.js`：本地编辑器固定开放内置能力，后续账户状态消息不会重新锁定功能。
- `util.js`：移除升级信封按钮。

仅开放扩展内置能力。AI 仍需配置对应服务；桌面 PDF 导出仍需本机 Chromium；Web 运行环境不支持的原生操作仍不可用。渲染资源与宿主扩展来自原版，修改覆盖层源代码均包含在此。

## 重建

提供官方 4.2.3 扩展目录作为基础：

```sh
python3 build.py --base /path/to/cweijan.vscode-office-4.2.3 --output /path/to/fresh-build
cd /path/to/fresh-build
npx @vscode/vsce package --no-dependencies
```

构建版本为 `4.2.3-local.3`。构建时会校验宿主替换位置及数量，遇到不同的打包内容会失败；须提供未修改的官方 4.2.3 目录，不能以已修改的本地免费版作为基础。

也提供 `upstream.patch` 便于审阅与移植。原版源码可从上述 GitHub 仓库获取。

集成测试：安装开发依赖后设置 `OFFICE_EXTENSION_ROOT` 指向构建目录，运行 `node test/browser-test.cjs` 和 `node test/browser-small-test.cjs`。可用 `MARKDOWN_TEST_FILE` 指定大文件测试副本，用 `CHROME_PATH` 指定 Chrome 可执行文件。


免费功能回归验证：

```sh
OFFICE_EXTENSION_BASE=/path/to/cweijan.vscode-office-4.2.3 python3 -m unittest discover -s test -p 'test_*.py'
OFFICE_EXTENSION_ROOT=/path/to/fresh-build node test/browser-free-features.cjs
```

浏览器测试使用模拟 VS Code 消息，验证 UI 与导出请求参数；宿主测试运行实际变换后的功能判断。尚未覆盖真实 VS Code 中全部 PDF 操作和文件导出的端到端验证。


自动翻页回归：`OFFICE_EXTENSION_ROOT=/path/to/fresh-build node test/browser-auto-pages.cjs`。覆盖滚轮向前／向后翻页、上一页末尾定位、惯性防连跳、PageDown／PageUp、手动开关、修改容量时保留编辑与全文保存、设置持久化。1600 行表格测试从旧版 21 页降为默认 6 页，首页 316 行表格数据。


## 阅读导航优化（local.3）

- 按稳定的文档标识独立保存阅读锚点、滚动位置和折叠光标。重开大文件时恢复；调整容量或外部插入文字时按源码文字与上下文重新定位。普通正文／表格优先使用文字锚点，无法映射时回退到页内滚动比例。跨页编辑撤销栈仍按原有方式清空。
- 全文搜索按原始源码偏移缓存匹配，支持同页多个重复词的逐个定位、前后循环，以及“第几处／总数”。同页搜索不重新渲染编辑器。匹配仅存在于隐藏链接地址等源码位置、无法可靠映射到预览时，会明确提示切换源码，避免高亮错误位置。
- 空闲时预处理前后相邻页，缓存最多三页的源码片段和重复表头；表格状态索引每个文档修订只构建一次。修改内容、改变容量或收到外部更新后失效重建。此缓存不保留编辑器 DOM，页面显示仍使用原版 Vditor 渲染。
- 初始化期间等待编辑器自己的光标恢复完成后再启用分页栏，避免搜索选区被初始化过程覆盖。

导航回归：`OFFICE_EXTENSION_ROOT=/path/to/fresh-build node test/browser-navigation.cjs`。覆盖同页重复词、匹配计数、前后搜索、重开阅读位置／光标恢复、容量调整、外部内容插入、文件隔离、全文保存和源码隐藏命中提示。
